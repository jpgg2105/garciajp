One task, three approaches

Requests to a voice assistant become JSON. A big model and a small model are prompted with 10 retrieved examples; the small model is also fine-tuned with LoRA on all of them.

With 100 examples

The prompted big model gets 55% of records right; the fine-tuned small model 32%.

With more examples

The fine-tuned model keeps climbing, to 64% at 2,000, while the prompted models flatten.

What it costs to run

The fine-tuned model reads 29× fewer tokens per request and needs about half the GPU time of the same model prompted.

Problem

Teams keep asking whether to fine-tune a small model or prompt a large one, and the answer depends on how much labelled data they have. I wanted the actual crossover point for one realistic task.

Solution

Structured extraction on MASSIVE (intent and slots as JSON), with pools of 100, 500 and 2,000 labelled examples. LoRA trains on each pool; the prompts retrieve their examples from the same pool. GPU runs in a Colab notebook, the API baseline locally, scored with paired intervals.

Architecture

Three ways to use the same examples

  1. Labelled pool100 / 500 / 2,000
  2. Prompt a big model10 retrieved examples
  3. Prompt a small modelsame 10 examples
  4. Fine-tune a small modelLoRA on the whole pool

How it was run

  1. Colab T4Qwen2.5-1.5B + PEFT
  2. Gemini APIfree tier
  3. 300 test requestspaired bootstrap
  • On the same small model, LoRA beat prompting by 12 points at 500 examples and 15 at 2,000.
  • Every method produced valid JSON almost always; at 100 examples the fine-tuned model failed by inventing labels it had never seen.
  • The fine-tuned model reads 31 input tokens per request against about 900 for the prompts, and trained in 3 minutes on a free GPU.
  • Hypotheses, metrics and LoRA settings were written down before the run.

Stack

Result

Exact-record accuracy at 100 / 500 / 2,000 labelled examples: Gemini Flash-Lite prompted 55 / 64 / 66%, Qwen 1.5B with LoRA 32 / 51 / 64%, the same Qwen prompted 31 / 40 / 49%. At 2,000 examples the fine-tuned model matched the larger one on whole records and intents, at 1/29 of the input tokens. Write-up: garciajp.com/writing/lora-vs-prompting/

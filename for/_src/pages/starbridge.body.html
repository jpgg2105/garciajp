Example snippets I wrote

How I would build it

  • Agenda item segmentation from timestamps and minutes, so every match has a short clip to cite.
  • Hybrid retrieval with BM25, embeddings and a cross-encoder rerank. I built the same setup in my document analyst project.
  • A stage classifier with a strict JSON schema and an evidence quote. If the quote is not in the transcript, the label gets thrown out.
  • An eval set built from rep feedback and run on every change, the same way my agent benchmark scores a change before it ships.

What I would check first

  • How transcripts come in today, how good the speech to text is, and whether speakers are labeled.
  • How much rep feedback already exists on saved Bridges. That is the fastest eval set to start from.
  • Whether reps want fewer results or more recall. The gate can lean either way.

How I would build it

  • The harness from my agent benchmark, which already runs in CI and tests without API keys by replaying recorded responses.
  • Case by case comparison with the last release, with a threshold per metric that the client agrees to up front.
  • A short release report in plain language, which doubles as the warranty log.
  • Production traces sampled into the golden set, with a person approving each new case.

What I would check first

  • Which AI projects are inside a warranty window right now.
  • Whether clients can share production logs, and under what rules.
  • How you handle model provider updates that nobody on the team asked for.
